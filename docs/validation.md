# 验证记录

日期：2026-09-14。测试环境：本机 Node.js、Vite、Codex 内置 Chromium 浏览器。

## 构建与几何

- `npm test` 成功：房间地面不重叠、共线墙段无重复、家具声明占地在所属房间内。
- 公共区可到达 12 个可走房间/过道，次卧1飘窗为非步入式窗台，不要求寻路进入。
- 沙发、餐桌、书桌活动接近点可达；路径分段细采样检查墙体/家具碰撞。
- 固定种子 7、42、2026 生成 60 条有效静态路径，采样点未穿过实体墙、家具或室外。蓝色窗段不能作为门洞通过。
- `npm run build` 成功，Three.js 单独分包，无构建警告。

## 浏览器实际操作

- 逐个选取九个分区并返回全屋，标题与显示同步。主卧保留套内区域；主卫单独可选。
- 检查全屋、主卧、次卧1、俯视、完整墙体、还原和专心看房/恢复菜单。
- 电视开关改变屏幕，打开时可见风景图案；主卧衣柜反复开合，移门叠合后可见内部层板和收纳。
- 调到22点、切换雨天、打开床头灯，观察到夜景、室外雨粒和床边局部照明。
- 沙发被占用时另一人物收到提示；小桃从沙发起身后，点击公共地面完成移动，实际结束位置约 X=3.095、Z=4.760，与目标 X=3.1、Z=4.8 的网格位置一致。
- 平面图弹窗渲染已检查，导出文件由同一份布局数据生成。

## 移动端

- 实际调整浏览器至390×844、320×720、844×390，检查全屋/单房间取景与横向溢出，均未出现页面横向溢出。
- 390px房间抽屉展开后画布实际大小为390×407；按钮高度44px，相邻水平/垂直间隙7px。
- 选房自动收起、面板滚动、专心看房与恢复、回到桌面布局已检查。
- 未完成真机多指、Safari动态地址栏、系统安全区实测。当前内置浏览器不支持 `Input.dispatchTouchEvent`，因此没有把视口调整当作双指操作通过。

## 已修复与边界

- 修复电视朝向、衣柜移门叠合、单房间长墙超出显示区、窄屏相机距离限制。
- 修复全屋阴影灯过多造成的WebGL着色器资源超限；关闭灯时不参加渲染，同时最多三个房间灯生成动态阴影。床头灯保留局部阴影。
- 剖面模式为统一低墙；完整墙体可切换。没有模拟承重结构、真实日照或工程精度。
- 初版不持久化家具开关和人物位置，刷新恢复默认状态。房间切换保留当前会话的状态。
- 所有显示尺寸是图纸近似复原；材料和家具外观仍需实拍校准。
