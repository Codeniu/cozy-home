# 慢慢住 · 互动 Q 版小家

根据提供的住宅平面图构建的本地 Three.js / WebGL 互动模型。

## 启动

在本项目目录运行：

```sh
npm install
npm run dev -- --port 5173
```

访问 http://127.0.0.1:5173/ 。依赖已安装时只需第二条命令。预览服务只监听本机，没有公开发布。

```sh
npm test       # 布局、碰撞、路径检查，并更新平面图 SVG
npm run build # 生成 dist
```

## 操作

- **空间**：全屋及九个房间/分区。主卧视图包含套内过道、主卫、南侧休闲区；主卫可单独打开。
- **视角**：鼠标拖动旋转、滚轮缩放，底部支持还原、俯视、完整墙体、平面图和专心看房。手机使用底部空间/家具/生活入口；面板可以滚动和收起。
- **家具**：点击模型中的家具，或在家具面板选择所在房间。电视显示画面；衣柜移门打开显示层板和收纳；房间灯、床头灯改变照明。
- **生活**：选择阿木或小桃，开启点击地面行走；点击可走空地发出指令。沙发、餐桌、书桌活动会先寻路再坐下，离座有过渡。被占用的活动点会提示稍候。
- **节奏**：随心活动、简单循环作息、手动陪伴。自动模式下手动指令优先，25 秒后恢复自主活动；手动陪伴不会自动发起新活动。
- **时间**：滑动一天中的时间；可开启自动流逝。晴、多云、雨改变环境光；晴夜显示月亮。光照是示意效果。
- **平面图**：可从页面导出 SVG，或直接打开 `public/floor-plan.svg`。

## 还原依据

唯一参考是 `public/reference.jpg`，即用户提供的户型图。没有室内实拍。

| 信息 | 状态 | 应用方式 |
| --- | --- | --- |
| 三室两卫，厨房在图上左侧，开放客餐厅在中间 | 图纸确认 | 保留邻接与主要门洞 |
| 主卧、次卧1、次卧2名称 | 图纸确认 | 按原图名称，不按面积重命名 |
| 主卫通过主卧套内走道进入 | 图纸支持 | 不从客餐厅穿墙进入 |
| 沙发朝向电视，卧室床头方位 | 图纸支持 | 保留相对位置 |
| 图上北箭头、宽约7970、房高2720 mm | 图纸标注 | X向右、Z向下、Y向上；模型采用近似米制 |
| 墙厚、门窗净尺寸、窗型 | 估计 | 基于图纸比例近似，不作为实测数据 |
| 主卧下方延伸区的实际用途 | 待确认 | 暂称南侧休闲区，保持开放相连 |
| 次卧1下方狭长区域 | 图纸推断 | 作为飘窗软垫，不设可走通道 |
| 配色、木纹、窗框、柜门形式、装饰 | 风格化估计 | 奶油暖色、浅木、鼠尾草绿与陶土粉 |

可以补充站在各房门口朝内拍摄的照片，进一步校正家具、材料、窗户及南侧空间用途。

## 文件

- `src/layout.js`：房间、墙段、门窗、家具、碰撞与导航。SVG 与三维模型共同读取。
- `src/main.js`：建模、状态、人物活动、光线及交互。
- `src/style.css`：桌面/手机布局。
- `public/floor-plan.svg`：当前模型的同源平面图。
- `docs/home-preview.png`：浏览器实际全屋截图。
- `docs/validation.md`：实际验证范围和限制。

参考图保留在项目中，未上传第三方，也没有公开托管。修改布局后运行 `npm test` 同步导出的平面图。
